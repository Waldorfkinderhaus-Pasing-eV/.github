# GitHub-Profil · Waldorfkinderhaus Pasing e. V.

Das öffentliche Organisationsprofil liegt in [profile/README.md](profile/README.md).
Texte, Logo und Gartenaufnahme basieren auf der [Kinderhaus-Website](https://www.waldorfkinderhaus-pasing.de/).

## Veröffentlichung

GitHub zeigt `profile/README.md` auf der Übersichtsseite der Organisation
[`Waldorfkinderhaus-Pasing-eV`](https://github.com/Waldorfkinderhaus-Pasing-eV),
sobald die Dateien im Standardbranch `main` dieses öffentlichen `.github`-Repositorys liegen.
Die Bilder werden aus `profile/assets/` über feste URLs im selben Branch geladen.
Bei einer Umbenennung der Organisation oder des Branches müssen diese URLs angepasst werden.

## Pflege

- Das Profil bleibt bewusst zeitlos. Freie Plätze, Termine, Öffnungszeiten und Stellenangebote werden auf der Website gepflegt.
- Logo und Gartenaufnahme stammen von der Website; ihre ursprünglichen Adressen stehen in [profile/assets/SOURCES.md](profile/assets/SOURCES.md).
- Für eine Textänderung genügt es, `profile/README.md` zu bearbeiten. Ein Build ist nicht nötig.
- Die Profilbilder sind lokal im Repository gespeichert; externe Badge- oder Bilddienste werden nicht benötigt.
